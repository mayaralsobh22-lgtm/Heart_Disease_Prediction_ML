# Heart Disease Prediction Using Machine Learning

## Overview

This project predicts whether a patient has heart disease using supervised machine learning techniques.

## Objective

Build and compare machine learning classification models to predict heart disease based on clinical features.

## Dataset

- Heart Disease Dataset (Kaggle)
- 918 patient records
- 11 clinical features

## Machine Learning Models

- Logistic Regression
- Random Forest

## Data Preprocessing

- Missing value checking
- Label Encoding
- Feature Scaling (StandardScaler)
- Train/Test Split (80/20)

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Results

Random Forest achieved the best performance with higher Accuracy, Recall, and ROC-AUC than Logistic Regression.
